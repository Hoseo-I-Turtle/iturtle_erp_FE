# 디자인이 없는 화면 목록

Penpot `02`~`05 Screens` 에 디자인이 없어 프론트에서 "준비 중"으로 막아 둔 화면 · 동작입니다.
Penpot 에 디자인을 추가한 뒤 코드로 구현하고, 끝나면 상태를 바꿉니다.

상태: `대기` → `디자인 완료` → `구현 완료`

## 1. 메뉴 · 링크는 있는데 막혀 있는 화면

| # | 화면 | 주소 | 들어가는 곳 | 관련 API | 상태 |
|---|------|------|------------|---------|------|
| 1 | 공지 목록 | `/notices` | 사이드바 "공지사항" (지금은 공지 상세로 바로 보냄) | `GET /notices` | 디자인 완료 |
| 2 | 작업 목록 | `/projects/:key/tasks` | 프로젝트 탭, 홈 "내 작업 · 모두 보기" | `GET /tasks?projectKey=` | 대기 |
| 3 | 마일스톤 | `/projects/:key/milestones` | 프로젝트 탭, 개요 "마일스톤 · 전체" | `GET /milestones?projectKey=` | 대기 |
| 4 | 프로젝트 자료 | `/projects/:key/files` | 프로젝트 탭 | `GET /documents?projectKey=` | 대기 |
| 5 | 자료 상세 | `/library/:id` | 자료실 글 제목, 고정 자료 | `GET /documents/{id}` | 대기 |
| 6 | 프로젝트 설정 나머지 탭 | `/projects/:key/settings` | 설정 왼쪽 메뉴: 일반 · 참여자 · 라벨 · 연동 서비스 · 보관 · 삭제 | `docs/api/30-project.md` | 대기 |

## 2. 버튼은 있는데 열리는 화면이 없는 것

| # | 화면 / 창 | 버튼 위치 | 상태 |
|---|----------|----------|------|
| 7 | 공지 쓰기 · 수정 | 공지 헤더 "공지 쓰기", 공지 상세 연필 | 대기 |
| 8 | 작업 만들기 | 프로젝트 헤더 "작업 만들기", 보드 열의 + | 대기 |
| 9 | 일정 추가 | 캘린더 헤더 "일정 추가" | 대기 |
| 10 | 회의록 쓰기 · 회의록 목록 | 프로젝트 회의록 헤더 "회의록 쓰기", "다른 회의록 · 전체", 캘린더 "이 날 회의록 만들기" | 대기 |
| 11 | 자료 올리기 | 자료실 헤더 "자료 올리기" | 대기 |
| 12 | 프로젝트 만들기 | 프로젝트 목록 헤더 | 대기 |
| 13 | 마일스톤 만들기 | 마일스톤 탭 헤더 | 대기 |
| 14 | 검색 결과 | 모든 화면 헤더의 검색창 | 대기 |
| 15 | 새로 만들기 메뉴 | 홈 등 헤더 "새로 만들기" (무엇을 만들지 고르는 메뉴) | 대기 |
| 16 | 구성원 추가 | 관리 · 구성원 헤더 | 대기 |
| 17 | 코드 그룹 · 행 추가 | 관리 · 공통코드 | 대기 |
| 18 | 회의록 수정 이력 보기 | 회의록 오른쪽 "수정 이력 · 보기" | 대기 |
| 19 | 스레드 글 수정 · 삭제 | 스레드 글 "고치기", 더 보기 | 대기 |

## 3. API 명세에서 "디자인 추가 필요"로 적힌 것

- 내 작업 (여러 프로젝트에 걸친 내 작업 모아 보기)
- 나머지는 위 1 · 2 와 겹침 (`docs/api/README.md` 2장 마지막 줄)

## 진행 순서

사이드바에서 바로 들어가는 것 → 프로젝트 기본 흐름 → 나머지 순으로 합니다.
Penpot 페이지 `06 Screens · 추가` 에 `Screen · 이름` 보드로 만들고, 기존 화면의 사이드바 · 헤더 · 카드 스타일을 그대로 씁니다.
`01 Screens-아이디어스케치` 의 공지사항 · 글쓰기 · 글 상세 · 회의록 시안을 참고합니다.

1. 공지 목록
2. 공지 쓰기
3. 작업 목록
4. 작업 만들기
5. 마일스톤 (목록 · 만들기)
6. 회의록 목록 · 쓰기
7. 자료 상세 · 자료 올리기 · 프로젝트 자료
8. 일정 추가
9. 프로젝트 만들기 · 설정 나머지 탭
10. 검색 결과 · 새로 만들기 메뉴
11. 관리: 구성원 추가 · 코드 추가
12. 회의록 수정 이력 · 스레드 수정/삭제
